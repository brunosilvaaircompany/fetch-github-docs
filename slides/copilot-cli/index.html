💡 O que é o GitHub Copilot CLI? 05:00 – 15:00

Ferramenta standalone que traz o poder do Copilot diretamente para o terminal — sem trocar de contexto.

  • git → gerencia repositórios locais/remotos
  • gh → interage com a plataforma GitHub
  • copilot → IA conversacional no terminal
# Instalação
npm install -g @github/copilot

# Pré-requisitos:
# Node.js 22+
# Assinatura Copilot (Free funciona!)

🚀 Principais capacidades

  • ✅ Sugere comandos com IA (OpenAI, Google)
  • ✅ Gera código e scripts no terminal
  • ✅ Gerencia issues e PRs via linguagem natural
  • ✅ Suporta imagens (paste / drag-and-drop)
  • ✅ Integra MCP (Model Context Protocol)
  • ✅ Cria agentes customizados (.github/agents/)
  • ✅ Delega tarefas ao Coding Agent (/delegate)
  • ✅ Modo headless: copilot -p "prompt"

⌨️ Slash commands essenciais

/login          → autenticar com o GitHub
/session        → detalhes da sessão atual
/context        → visualizar uso de tokens
/usage          → estatísticas de requests
/share gist     → salvar sessão como Gist
/delegate       → delegar ao Coding Agent
/exit           → encerrar a sessão

Atalhos rápidos

  • @arquivo → incluir arquivo no contexto
  • !comando → executar shell diretamente
  • Ctrl+L → limpar tela
  • Shift+Tab → alternar para Plan Mode

🏗️ Casos de uso no dia a dia

  • Criar issues a partir de templates sem abrir o browser
  • Gerar código baseado em imagens + descrição
  • Escrever e rodar testes automatizados
  • Criar branches, commits e PRs pelo chat
  • Delegar tarefas complexas ao Coding Agent
  • Documentar código sem sair do terminal
  • Automatizar workflows com modo headless (-p)
  • Compartilhar sessões como Gist (/share gist)

⚙️ Setup no Codespace

# Instalar o Copilot CLI
npm install -g @github/copilot

# Verificar instalação
copilot --version

# Iniciar sessão com todos os recursos
copilot --enable-all-github-mcp-tools

# Autenticar (dentro da sessão Copilot)
/login
⚠️ Atenção: Se reiniciar o Codespace, autentique novamente com /login ou !gh auth login

📋 Step 1 — Instalação + Issue via Copilot CLI

Prompt para criar a issue:

"Create a GitHub issue for a Node.js CLI calculator app
 using .github/ISSUE_TEMPLATE/feature_request.md template.
 I want to request a feature for basic arithmetic operations:
 addition, subtraction, multiplication, division.
 The calculator should be in calculator.js
 Create the issue directly using gh CLI commands."
  • ✅ Copilot lê o template, preenche e cria a issue automaticamente
  • ⚠️ Confirme o uso do gh issue quando solicitado

💻 Step 2 — Código com imagem + issue

# Iniciar com todas as permissões habilitadas
copilot --allow-all --enable-all-github-mcp-tools

Prompt com imagem no contexto:

"@images/js-calculator.png help me create a Node.js CLI
 calculator app based on the four basic math operations
 in this image and outlined in the latest issue.
 Create the code in the 'src' directory."
  • Depois: criar testes, rodar e validar
  • Ao final: commit + push via prompt natural
  • 💡 Use Ctrl+O para ver o output dos testes!

➕ Step 3 — Expandir funcionalidades

Nova issue para expandir: Modulo, Exponentiation, Square Root

"Add these functions to my existing calculator.js:
 1. modulo(a, b)
 2. power(base, exponent)
 3. squareRoot(n) - with error handling for negative numbers"

Testes a expandir:

  • src/tests/calculator.test.js
  • Edge case: divisão por zero
  • Edge case: raiz de número negativo
💡 Dica: Use /share gist para salvar sua sessão!

🔀 Step 4 — PR + Code Review + Merge

Criar o PR:

"Create a pull request from the current branch with title
 'Add calculator enhancements'. Add @copilot as reviewer
 and request a review. List the PR link when created."

Vincular issues & fazer merge:

"Link the PR to both issues so they close automatically."
"Merge the pull request and close the attached issues."
"List the closed issues to confirm both are closed."
✅ Todo o ciclo issue → código → PR → merge sem sair do terminal!

🧠 Human in the Loop — Sempre!

O Copilot é um assistente, não um substituto.

  • ✅ Revise todo código gerado antes de aceitar
  • ✅ Valide os testes — eles devem fazer sentido
  • ✅ Leia as mensagens de commit antes de confirmar
  • ✅ Analise o PR antes do merge
  • ✅ Questione sugestões que pareçam incorretas

Como corrigir quando a IA erra:

  • Ajuste o prompt com mais contexto
  • Forneça exemplos (imagens, arquivos com @)
  • Limpe o histórico com /clear
  • Use ! para comandos shell diretos

💰 Economia de contexto e tokens 50:00 – 55:00

❌ Evite:

  • Manter arquivos desnecessários abertos
  • Sessões longas com muito histórico
  • Usar --allow-all em produção

✅ Faça:

  • Use /context para monitorar tokens
  • Use /usage para acompanhar requests premium
  • Prefira autocomplete para tarefas simples
  • Inicie nova sessão com /clear ao mudar de tarefa
  • Use copilot -p "prompt" para automações

🎯 Contexto específico e personalização

Referencie arquivos diretamente:

@src/calculator.js  → inclui o arquivo
@images/calc.png    → inclui imagem

Flags úteis:

--enable-all-github-mcp-tools
--allow-all    # use com cuidado!
-p "prompt"    # modo headless

Personalize o projeto:

- Use TypeScript com strict mode
- Siga o padrão REST para APIs
- Documente funções com JSDoc
  • .github/agents/ → agentes customizados
