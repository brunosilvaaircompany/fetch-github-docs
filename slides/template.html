🧠 Human in the Loop

  • O Copilot é um assistente, não substitui o desenvolvedor
  • Todo código gerado deve ser revisado
  • Pull Requests precisam de validação humana
  • Sugestões da IA requerem análise crítica

🔄 Lidando com Imprevistos

  • Ajuste o prompt — adicione mais contexto
  • Limpe o histórico do chat quando necessário
  • Use #arquivo para referenciar contexto específico
  • Demonstre como guiar a IA até a resposta esperada

✅ Boas Práticas 50:00 – 55:00

Economia de Contexto / Tokens

  • Feche arquivos que não são relevantes para a tarefa
  • Limpe conversas antigas antes de iniciar novo contexto
  • Prefira autocomplete para tarefas simples
  • Reduzir contexto = respostas mais precisas e rápidas

📌 Contexto Específico

  • Referencie arquivos com # no chat
  • Use .github/copilot-instructions.md para instruções persistentes do projeto
  • Configure instruções de linguagem, padrões e restrições
# .github/copilot-instructions.md
- Use TypeScript com strict mode habilitado
- Siga o padrão REST para APIs
- Documente funções públicas com JSDoc
