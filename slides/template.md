# Template de Apresentação de 60 Minutos

Template padronizado para criar e conduzir treinamentos sobre **GitHub Copilot** com duração de **1 hora**.

---

## 🕒 Agenda do Treinamento (60 minutos)

### ⏱️ 00:00 – 05:00 (5 min) — Abertura e Alinhamento Inicial

#### Boas-vindas e Contextualização

- Cumprimente a equipe.
- Faça uma breve recapitulação do encontro anterior (quando aplicável).
- Apresente o tema do dia.

#### Regras do Jogo (Timebox)

- Explique que, devido ao tempo limitado, o foco será acompanhar a demonstração.
- Oriente os participantes a reproduzirem os exercícios posteriormente utilizando a gravação e a documentação disponibilizadas.

---

### ⏱️ 05:00 – 15:00 (10 min) — Teoria, Conceitos e Casos de Uso

#### O que é a ferramenta/recurso?

Apresente uma explicação objetiva sobre o recurso abordado, por exemplo:

- MCP
- Agent Mode
- Outro recurso do GitHub Copilot

#### Por que usar? (Benefícios)

Explique como a ferramenta:

- acelera o desenvolvimento;
- reduz trabalho manual;
- fornece mais contexto ao Copilot;
- aumenta a produtividade.

#### Casos de Uso Reais

Apresente exemplos práticos, como:

- Refatoração de código;
- Automação de testes;
- Criação de queries SQL;
- Desenvolvimento de APIs;
- Geração de documentação;
- Correção de bugs.

#### Documentação Oficial

Compartilhe links para:

- Repositório oficial;
- Documentação;
- GitHub Docs;
- Changelog;
- Materiais de referência.

---

### ⏱️ 15:00 – 20:00 (5 min) — Preparação do Ambiente

#### Apresentação do Repositório

- Mostre o repositório utilizado no treinamento.
- Explique seu propósito.

Exemplos:

- GitHub Skills
- Repositórios de demonstração
- Projetos internos

#### Fork / Clone

Demonstre rapidamente como:

- fazer o fork;
- clonar o repositório;
- preparar o ambiente.

#### Inicialização do Ambiente

- Abrir no GitHub Codespaces; **ou**
- Abrir localmente no VS Code.

Valide:

- acesso ao GitHub Copilot;
- permissões necessárias;
- extensões instaladas.

---

### ⏱️ 20:00 – 50:00 (30 min) — Hands-on / Demonstração Prática

#### Execução por Etapas

Realize o exercício passo a passo mostrando o uso do Copilot:

- Chat;
- Terminal;
- Inline no editor;
- Agentes (quando aplicável).

#### Engenharia de Prompt

Demonstre:

- exemplos de prompts genéricos;
- exemplos de prompts específicos;
- técnicas de planejamento antes da execução.

#### Human in the Loop

Reforce continuamente que:

- o Copilot é um assistente;
- todo código deve ser revisado;
- Pull Requests devem ser validados;
- sugestões da IA precisam de análise crítica.

#### Lidando com Imprevistos

Caso a IA apresente respostas incorretas:

- ajuste o prompt;
- forneça mais contexto;
- limpe o histórico do chat quando necessário;
- mostre como conduzir a IA até a resposta esperada.

---

### ⏱️ 50:00 – 55:00 (5 min) — Boas Práticas

#### Economia de Contexto/Tokens

Explique como:

- fechar arquivos desnecessários;
- limpar conversas antigas;
- utilizar autocomplete quando possível;
- reduzir consumo de contexto.

#### Uso de Contexto Específico

Mostre recursos como:

- referência de arquivos com `#`;
- arquivo `.github/copilot-instructions.md`;
- instruções específicas do projeto.

---

### ⏱️ 55:00 – 60:00 (5 min) — Encerramento

#### Resumo

Faça uma revisão dos principais aprendizados e do valor entregue pela ferramenta.

#### Perguntas e Respostas (Q&A)

Abra espaço para dúvidas via:

- chat;
- microfone;
- comentários.

#### Próximos Passos

Informe:

- onde ficará a gravação;
- onde encontrar a documentação;
- tema do próximo encontro;
- canais de suporte.

Finalize agradecendo a participação de todos.

---

# 💡 Dica para o Instrutor

Evite construir projetos do zero durante a apresentação.

Sempre que possível:

- utilize repositórios prontos;
- aproveite exemplos da comunidade (como **GitHub Skills** ou **Awesome Copilot**);
- mantenha o foco em demonstrar como o GitHub Copilot auxilia no desenvolvimento, em vez de gastar tempo criando toda a base do projeto durante a live.
